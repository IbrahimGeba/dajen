## 📋 نبذة عن التطبيق

**Dagen** هو تطبيق شامل مصمم خصيصاً للمزارعين لإدارة دوراتهم الزراعية بكفاءة عالية. يوفر التطبيق أدوات متقدمة لتتبع المحاصيل، إدارة الصحة الزراعية، التواصل مع التجار، ومراقبة الأداء المالي للدورة من البداية حتى الحصاد.

يجمع Dagen بين إدارة الدورات الزراعية والسوق الإلكترونية، مما يسهل على المزارعين بيع منتجاتهم مباشرة والتواصل مع المشترين.

## ✨ المميزات الرئيسية

### 🔄 إدارة الدورات الزراعية
- ✅ إنشاء دورات زراعية جديدة بسهولة
- ✅ متابعة يومية تفصيلية لحالة الدورة
- ✅ حساب أداء الدورة تلقائياً
- ✅ إكمال الدورة مع تقارير شاملة
- ✅ تتبع المراحل المختلفة للنمو

### 🏥 إدارة صحة المحاصيل/الثروة
- 🦠 تتبع الأمراض والمشاكل الصحية
- 💉 جدول تطعيمات منظم
- 📋 خطط العلاج المتقدمة
- 📊 متطلبات صحية حسب عمر المحصول
- ⚠️ إنذارات صحية فورية

### 📊 المتابعة اليومية المتقدمة
- 📍 تسجيل استهلاك الأعلاف/الموارد
- ⚖️ مراقبة الأوزان والأحجام
- 🌡️ تتبع درجات الحرارة والرطوبة
- 💧 قياس استهلاك المياه
- 🧪 البيانات التغذوية والدقيقة

### 💰 الإدارة المالية الشاملة
- 💵 بيان حساب مفصل لكل دورة
- 📈 حساب التكاليف الكاملة
- 💹 تتبع الأرباح والعائد
- 📊 تقارير مالية شاملة
- 🎯 تحليل الربحية

### 🛒 السوق الإلكترونية
- 🌾 عرض منتجاتك للبيع
- 👥 عرض ملفات التجار والمشترين
- 💬 التواصل المباشر مع المشترين
- ⭐ نظام تقييمات وثقة
- 🔔 تنبيهات الطلبات الفورية

### 📱 الميزات التقنية
- 🔔 إشعارات فورية للأحداث المهمة
- 💬 نظام الرسائل المدمج

### الهيكل الأساسي للمشروع
```
lib/
├── models/              # نماذج البيانات
├── screens/             # الشاشات الرئيسية

│   ├── health/
│   ├── tracking/
│   ├── financial/
│   ├── market/
```
