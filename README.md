## 📋 نبذة عن التطبيق

**Dagen** هو تطبيق شامل مصمم خصيصاً للمزارعين لإدارة دوراتهم  بكفاءة عالية. يوفر التطبيق أدوات متقدمة لتتبع المحاصيل، إدارة الصحة ، التواصل مع التجار، ومراقبة الأداء المالي للدورة من البداية حتى الحصاد.

يجمع Dagen بين إدارة الدورات  والسوق الإلكترونية، مما يسهل على المربيين بيع منتجاتهم مباشرة والتواصل مع المشترين.

---

## ✨ المميزات الرئيسية

### 🔄 إدارة الدورات 
- ✅ إنشاء دورات جديدة بسهولة
- ✅ متابعة يومية تفصيلية لحالة الدورة
- ✅ حساب أداء الدورة تلقائياً
- ✅ إكمال الدورة مع تقارير شاملة
- ✅ تتبع المراحل المختلفة للنمو

### 🏥 إدارة صحة المحاصيل/الثروة
- 🦠 تتبع الأمراض والمشاكل الصحية
- 💉 جدول تطعيمات منظم
- 📋 خطط العلاج المتقدمة
- 📊 متطلبات صحية حسب عمر المحصول
- ⚠️ إنذارات صحية فورية

### 📊 المتابعة اليومية المتقدمة
- 📍 تسجيل استهلاك الأعلاف/الموارد
- ⚖️ مراقبة الأوزان والأحجام
- 🌡️ تتبع درجات الحرارة والرطوبة
- 💧 قياس استهلاك المياه
- 🧪 البيانات التغذوية والدقيقة

### 💰 الإدارة المالية الشاملة
- 💵 بيان حساب مفصل لكل دورة
- 📈 حساب التكاليف الكاملة
- 💹 تتبع الأرباح والعائد
- 📊 تقارير مالية شاملة
- 🎯 تحليل الربحية

### 🛒 السوق الإلكترونية
- 🌾 عرض منتجاتك للبيع
- 👥 عرض ملفات التجار والمشترين
- 💬 التواصل المباشر مع المشترين
- ⭐ نظام تقييمات وثقة
- 🔔 تنبيهات الطلبات الفورية

### 📱 الميزات التقنية
- 🔔 إشعارات فورية للأحداث المهمة
- 💬 نظام الرسائل المدمج
- 🔐 أمان عالي للبيانات
- ⚡ أداء سريع وسلس

## 📚 التوثيق

### الهيكل الأساسي للمشروع
```
lib/
├── models/              # نماذج البيانات
├── screens/             # الشاشات الرئيسية
│   ├── home/
│   ├── cycle/
│   ├── health/
│   ├── tracking/
│   ├── financial/
│   ├── market/
│   └── messages/
├── services/            # خدمات API والبيانات
├── providers/           # إدارة الحالة
├── widgets/             # الأدوات المعاد استخدامها
└── utils/              # الأدوات والثوابت
```

### API المستخدمة
- **Firebase Authentication** - تسجيل المستخدمين
- **Firestore Database** - تخزين البيانات
- **Cloud Messaging** - الإشعارات الفورية
- **Google Maps API** - تحديد الموقع والملاحة
